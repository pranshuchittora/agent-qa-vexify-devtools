# Contributing to awesome-devtools

Thanks for wanting to contribute! 🎉

## How to Add a Tool

1. Find the appropriate category section
2. Add a new row to the table with:
   - **Tool** — link to the project website
   - **Description** — one clear sentence
   - **License** — open-source license (or "Free/Pro" for SaaS)
   - **Notes** — what makes it special

## Guidelines

- ✅ **Open source or widely-used commercial tools** only
- ✅ **No dead projects** — if the last commit is >2 years ago, think twice
- ✅ **Add to the most relevant category** — don't duplicate across sections
- ✅ **Keep descriptions concise** — one sentence, no marketing fluff
- ✅ **Use the table format** — link, description, license, notes columns

## Categories

If you need a new category, open an issue first to discuss.

## PR Checklist

- [ ] Link is valid and points to the project
- [ ] Description is accurate and concise
- [ ] License is correctly identified
- [ ] Table is sorted alphabetically
- [ ] No duplicates

## Quality Bar

This list is meant to be **curated, not comprehensive**. A tool belongs here if:
1. It's actively maintained
2. It's genuinely useful in a day-to-day developer workflow
3. It has a solid reputation in its space

Don't add tools just because they exist — add tools you'd actually recommend to a colleague.
